# Next-Ethereum Project

## Overview
Next-Ethereum is a decentralized application (dApp) that integrates blockchain technology with a user-friendly interface. The application allows users to connect their Tronlink wallets and interact with the 7 Saints platform, which combines spirituality and cryptocurrency.

## Features
- **Wallet Connection**: Users can connect their Tronlink wallets seamlessly.
- **Deposit and Withdrawal Sections**: Users can deposit and withdraw TRX with clear instructions and requirements.
- **Responsive Design**: The application is designed to be responsive and user-friendly across devices.

## Installation
To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd Next-Ethereum
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage
To run the application in development mode, use the following command:
```
npm run dev
```

Visit `http://localhost:3000` in your browser to view the application.
